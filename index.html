🌐 Salon multijoueur

Prototype réseau : plateau partagé et tours synchronisés pour le jeu de base. Les mains ne sont pas encore privées et les règles avancées ne sont pas sécurisées. Ne pas utiliser pour une partie compétitive.

Code du salon :

Joueurs connectés

    En attente du lancement par l’hôte.

    Commandes : pendant le placement initial, clique sur une intersection puis une arête. Après les placements, les boutons de construction, d'échange et de dés apparaissent dans l'interface de jeu sous le plateau. Le mode Villes et Chevaliers en réseau n'est pas encore disponible.
